# Contributing to IRCTC Backend

Thank you for your interest in contributing! Please follow these guidelines.

## Code Style

- Use ESLint for code quality
- Follow the existing code structure
- Use meaningful variable and function names
- Add comments for complex logic

## Before You Start

1. Create a feature branch: `git checkout -b feature/your-feature-name`
2. Make your changes
3. Test thoroughly: `npm run test`
4. Commit with clear messages: `git commit -m "feat: add user authentication"`

## Commit Message Convention

```
type(scope): subject

body (optional)
footer (optional)
```

**Types**: feat, fix, docs, style, refactor, test, chore

**Example**: `feat(auth): add email OTP verification`

## Pull Request Process

1. Update README if needed
2. Add tests if applicable
3. Ensure no sensitive data in commits
4. Describe changes in PR description
5. Request review from maintainers

## Reporting Bugs

1. Check if issue already exists
2. Include steps to reproduce
3. Add environment details
4. Attach error logs if available

## Questions?

Open an issue with the `question` label.

Happy contributing! 🚀
